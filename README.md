❌-⭕ Tic Tac Toe Game

A simple and interactive Tic Tac Toe web application built using front-end technologies. This game allows two players to play against each other in a classic 3×3 grid format with a smooth and user-friendly interface.

🚀 Features

🎮 Two-Player Mode – Play with a friend on the same device

🧠 Game Logic Implementation – Win/draw detection system

🔄 Restart Option – Easily reset the game anytime

📱 Responsive Design – Works on all screen sizes

✨ Interactive UI – Clean and engaging user interface

🛠️ Technologies Used

HTML5 – Structure of the game

CSS3 – Styling and layout

JavaScript – Game logic and interactivity

🎯 How to Play

1.The game is played on a 3×3 grid

2.Player 1 is X and Player 2 is O

3.Players take turns marking a cell

4.The first player to get 3 marks in a row (horizontal, vertical, or diagonal) wins

5.If all cells are filled and no one wins, the game ends in a draw
